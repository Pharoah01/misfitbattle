## Features

### Authentication
Secure user authentication system with session management and profile completion.

### Submission System
Code submission and evaluation system for challenges.

### Challenge System
Interactive coding challenges with difficulty levels (Easy, Medium, Hard) and real-time preview.

### Security
Advanced security features including API endpoint obfuscation, attack detection, and admin alerts.

## Technology Stack

### Frontend
- React 18 with TypeScript
- Tailwind CSS for styling
- Monaco Editor for code editing
- Vite for build tooling

### Backend
- Django 4.2 with Python
- PostgreSQL database
- Django REST Framework
- Gunicorn for production server

## Deployment

- **Frontend**: Deployed on Netlify
- **Backend**: Deployed on AWS EC2

## Project Architecture

Modern full-stack architecture with separate frontend and backend services, secure API communication, and scalable deployment infrastructure.
